让麦麦学会从贴吧搬石：选好要逛的吧，定时或手动搬一轮，把整帖渲染成一张长图发进群，或者打包成聊天记录。

---

## 注意事项

- **吧的配置**：在「内置吧（可多选）」中勾选常用吧（默认仅勾选「搬石」），未列出的吧写入「自己加的吧」，每行一个；吧名末尾的「吧」字可省略。
- ⚠️ **反爬拦截**：出现 403 或安全验证时，本轮中止并冷却 15 分钟，不会被当作「无新帖」；调大「抓取 → 请求间隔」可降低触发概率。
- **去重机制**：已搬运的帖子不会重复搬运；记录保存在 `data/plugins/mizuku003.tieba-share/moved.json`（默认每吧 500 条），需要重新搬运时使用 `/搬石 重置 [吧名]`。
- **发送内容**：每帖都会渲染成长图（过长会切成多张），没有「关掉长图」的开关 —— 关掉它就没有任何内容可发了。「发送」一节只决定是否打包成聊天记录、是否带上视频。长图渲染失败时这一帖不会发送，留到下一轮重试，不会退发文字。
- **长图样式**：「贴吧原页面」按手机版页面截图（顶栏、页脚、推广按钮已清除）；「自绘卡片」由插件排版，宽度更小、更省流量。两种样式都会把正文里的插图补进长图，数量受「长图里最多几张图」限制。
- **聊天记录**：开启「打包成聊天记录」后，本轮内容合并为一条聊天记录。长图以本地文件路径的形式放进去，因此不受帧大小限制；装不下的帖子会改为单独发送，不会重复也不会被吞掉。
- **楼中楼**：每层正文下会带上几条评论，楼主自己的回复优先。评论正文、帖子点赞数与翻页都走贴吧 protobuf 接口取得；该接口不提供评论点赞数，因此评论无法按赞排序。
- **视频**：视频帖连同视频一起发送；超过「视频大小上限」的视频整条跳过，连链接也不发。
- ⚠️ **适配器支持**：视频经宿主的自定义消息段通道发送，NapCat / snowluma 支持，其他适配器可能无法接收（此时仅显示链接）。
- **会话范围**：仅向群聊发送；同一群每轮只投递一条。群名单默认是**白名单**且默认为空，也就是装好后哪个群都不发，要在「定时 → 群名单」里加上群号才会生效。
- ⚠️ **代理**：插件不读取系统代理（`trust_env=False`），如需代理请在「抓取 → 代理」中填写。
- **自动搬运**：默认关闭。开启后按「隔多少分钟搬一次」或「每天定点」轮询（填写定点后忽略间隔）；启动后不会立即搬运，需等到下一个时间点。两种模式均按绝对时刻排期，重启或单轮耗时过长都不会顶掉时间点。
- **免打扰时段**：默认 23:00~08:00，区间内跳过定时搬运且不补发；`/搬石` 等手动指令与麦麦调用不受影响。
- **发送时间不准**：填写「提前开始」后，插件提前取回帖子，到点再发送；间隔与定点两种模式均生效。
- **`/搬石` 与 `/搬视频`**：前者按配置搬运，后者只搬运视频帖。
- **工具调用的发送参数**：由面板「工具」一节单独控制，与「发送」互不影响。
- **仅供个人学习与自用**：免登录读取贴吧公开页面，请遵守贴吧服务条款。
- **内容版权**：搬运内容的版权归原作者所有；插件仅做转发，不代表作者观点。
- **使用风险自负**：作者不对因使用本插件产生的任何后果负责（内容争议、IP 受限、群聊体验等）。

## 功能特性

| 功能 | 说明 |
|---|---|
| 逛指定的吧 | 面板勾选内置吧（可多选），也可自行填写吧名 |
| 定时搬运 | 按「基准时刻」起算的固定间隔，或每天定点（可配置多个时间）；支持免打扰时段 |
| 手动搬运 | `/搬石` 按配置搬运一轮；`/搬视频` 仅搬运视频帖 |
| 模型自主搬运 | 提供 `tieba_share` 工具，麦麦可自行选帖搬运；发送参数由「工具」一节控制 |
| 发送形态 | 整帖长图（自绘卡片 / 贴吧原页面），可选打包为聊天记录、附带视频 |
| 群黑白名单 | 默认白名单，名单为空 = 哪个群都不发 |
| 去重 | 已搬运的帖子不重复搬运，记录可查看、可清空 |
| 内容筛选 | 支持最少回复数、最少点赞数、标题屏蔽词、跳过置顶帖 |
| 楼层评论 | 每层正文下附带楼中楼，楼主回复优先 |

## 安装

1. 将插件目录放入宿主的 `plugins/` 目录。
2. 在 WebUI 插件页启用（安装后默认关闭）。
3. 在 WebUI 面板中修改配置；插件目录下的 `config.toml` 由宿主按默认值生成，无需手写。
4. 在「搬石」一节配置吧：勾选内置吧，未列出的吧填入「自己加的吧」。

搬运记录保存在宿主的 `data/plugins/mizuku003.tieba-share/` 目录。依赖 `httpx` 已在 `_manifest.json` 中声明，由宿主自动安装。

## 指令

| 指令 | 说明 |
|---|---|
| `/搬石` | 按配置搬运一轮，发送到当前群 |
| `/搬视频` | 本轮仅搬运视频帖，忽略「只搬哪种帖」的设置 |
| `/搬石 状态` | 查看每个吧的搬运条数与最后一次搬运时间（仅管理员） |
| `/搬石 重置 [吧名]` | 清空搬运记录；不填吧名则清空全部（仅管理员） |
| `/搬石 重置 冷却` | 手动解除反爬冷却（仅管理员） |
| `/搬石 帮助` | 输出用法说明 |

`/搬石` 与 `/搬视频` 需要权限：管理员，或「可搬石的群」里列出的群（整群可用）。`/搬石 状态`、`/搬石 重置`、`/搬石 重置 冷却` 属于维护命令，仅管理员可用。名单在插件配置的「权限」一节填写，直接填 QQ 号即可（`qq:123456` 的旧写法同样识别）；主程序终端始终可用。

> 两张名单均留空时，插件沿用宿主配置 `[plugin] permission` 中的账号。该名单由整个插件系统共用，修改会影响其他插件，因此建议使用插件自身的「权限」一节。

## 让麦麦自己搬

插件向麦麦提供 `tieba_share` 工具，在群内说「搬个石」即可触发，结果发送到当前会话。

- **发送参数**：定时搬运与 `/搬石` 使用「发送」一节，工具调用使用「工具」一节，两节互不影响。
- **吧的范围**：「限定吧」留空时麦麦可选择任意吧；填写后仅限于所列的吧。
- **可用参数**：吧名（不填则使用配置值）、条数（默认 1，最多 5）、帖子类型（默认跟随「工具」一节，也可临时指定）。
- 工具调用同样受去重、帖子类型筛选与「带原帖链接」影响，并与手动搬运共用同一把锁；上一轮未结束时调用会提示稍后再试。

### 插件

| 配置项 | 默认 | 说明 |
|---|---|---|
| 启用插件 | 关 | 关掉后不再响应任何命令 |

### 搬石

| 配置项 | 默认 | 说明 |
|---|---|---|
| 内置吧（可多选） | 搬石 | 内置 12 个常用吧（搬石、小黑盒笑话、弱智、地狱笑话、dinner笑话、孙笑川、核战避难所、2ch、复制粘贴、反二次元、冷笑话、幽默老中） |
| 自己加的吧 | 空 | 一行一个吧名；末尾带不带「吧」字均可 |
| 每个吧搬几条 | 3 | 每个吧取最后回复最新的几条 |
| 最少回复数 | 0 | 回复数低于此值的帖子不搬；0 = 不限 |
| 最少点赞数 | 10 | 点赞低于此值的帖子不搬；0 = 不限 |
| 跳过置顶帖 | 开 | 不搬吧内置顶帖 |
| 标题屏蔽词 | 水贴、水楼、+3 | 标题含这些词的帖子不搬；留空 = 不屏蔽 |
| 去重记录条数 | 500 | 每个吧保留的去重记录条数；超出后丢弃最早的记录 |

### 定时

| 配置项 | 默认 | 说明 |
|---|---|---|
| 自动搬石 | 关 | 开启后按下面的时间自动搬运 |
| 隔多少分钟搬一次 | 120 | 两次自动搬运的间隔分钟数；填了「每天定点」后本项失效 |
| 基准时刻 | 0:00 | 间隔从这一刻往后数，如 0:00 + 120 分钟 = 0、2、4……22 点 |
| 提前开始（秒） | 30 | 提前多少秒开始取帖，到点准时发出；间隔和定点都管 |
| 每天定点 | 空 | 每天几点搬，如 09:30、21:00，一行一个；24:00 表示零点 |
| 免打扰开始 | 23:00 | 格式 HH:MM；留空 = 不启用免打扰。默认 23:00~08:00 深夜不发 |
| 免打扰结束 | 08:00 | 格式 HH:MM；支持跨午夜。默认 23:00~08:00 深夜不发 |
| 群名单模式 | 白名单 | 白名单 = 只发下面名单里的群；黑名单 = 下面名单里的群不发 |
| 群名单 | 空 | 填群号，一行一个。默认白名单且名单为空 = **哪个群都不发**，要发先在名单里加上群号 |

| 配置项 | 默认 | 说明 |

## 数据来源

- 帖子列表与正文：贴吧移动站（`tieba.baidu.com/mo/q/m`），免登录，只用访客 cookie。
- 图片：帖内插图按原图取，取不到时退回带签名的缩略图。
